# Pitch math: Python bindings

Python bindings for [pitch-math](https://github.com/chethandvg/pitch-math), built from the Rust core with PyO3 and maturin. Function names and results are identical to the Rust crate; the shared golden vectors check it in CI.

```bash
pip install "git+https://github.com/chethandvg/pitch-math@v0.1.1#subdirectory=bindings/python"
```
